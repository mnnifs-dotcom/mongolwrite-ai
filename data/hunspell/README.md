# Монгол зөв бичгийн толь

`mongoltoli.mn` (Монгол хэлний их тайлбар толь) нь тайлбар толь бөгөөд
зохиогчийн эрхтэй. Тэндээс үг хуулаагүй.

Энэ хавтаст [dict-mn](https://github.com/bataak/dict-mn) Hunspell файлууд орно
(Firefox, LibreOffice-ийн монгол spellcheck). Татах:

```bash
python scripts/fetch_mn_dictionary.py
```
